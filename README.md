Coletânea de soluções empresariais desenvolvidas para organização, centralização e otimização de processos administrativos.

## Contexto empresarial

Os projetos deste repositório foram desenvolvidos durante minha atuação profissional como Analista de Dados em uma empresa do setor de logística.

Cada solução surgiu de uma necessidade real do ambiente empresarial, abrangendo processos administrativos, gestão de pessoas, controle de estoque e acompanhamento operacional.

O objetivo foi transformar processos manuais e informações descentralizadas em ferramentas estruturadas, reutilizáveis e de fácil manutenção.

## Projetos

| Projeto | Descrição |
| --- | --- |
| [Banco de Colaboradores](./banco-de-colaboradores/) | Centralização de cadastros, consultas e pendências cadastrais. |
| [Controle de Estoque](./controle-de-estoque/) | Controle de uniformes, movimentações, saldos e necessidade de reposição. |
| [Gestão de Férias](./gestao-de-ferias/) | Acompanhamento de períodos, programações, saldos e alertas de RH. |
| [Controle de Pontualidade](./controle-de-pontualidade/) | Acompanhamento de presença, atrasos, escalas e indicadores semanais. |

## Tecnologias e recursos

- Microsoft Excel 2019
- Power Query (linguagem M)
- Fórmulas e funções do Excel
- Validação de dados
- Segmentação de dados
- Dashboards e indicadores
- Modelagem e transformação de dados

## Competências aplicadas

- Levantamento de necessidades empresariais.
- Análise e melhoria de processos.
- Modelagem e estruturação de dados.
- Implementação de regras de negócio.
- Automação de cálculos e consolidações.
- Qualidade e consistência das informações.
- Desenvolvimento de soluções de fácil utilização e manutenção.

## Demonstrações

Cada projeto possui documentação individual e uma versão funcional demonstrativa, permitindo explorar suas principais funcionalidades utilizando dados fictícios.

Os arquivos foram preparados para utilização no Microsoft Excel 2019.

## Confidencialidade

Este repositório possui finalidade demonstrativa e de portfólio profissional.

As soluções foram desenvolvidas em contexto empresarial real. Entretanto, os arquivos disponibilizados utilizam dados fictícios, preservando a confidencialidade das informações corporativas e pessoais.
